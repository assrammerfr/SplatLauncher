## Registers that settle the fault
- x9 = 0 (head pointer, NULL), x20 = 0x1f = 31 (thread index),
  x11 = 0xf8 = 248 (31 * 8), x10 = 0x1f, x2 = 0, x19 = f2902d0.
- The x10 = -0x60 theory is dead: x10 is 31, so
  `ldr x9, [x10, #0x1D8]` would be 0x1f + 0x1D8 = 0x1F7, not 0x178.

## Fault mechanism
The loop after the mutex-lock call is, in effect:
  for (p = head; p != &list; p = p->next)
      *(p + idx*8 + 0x80) = 0;
With p = 0 (NULL), idx = 31:
  0 + 31*8 + 128 = 0 + 248 + 128 = 376 = 0x178
That is the fault address, exactly. The loop exit condition is
p != &list (sentinel), not p != NULL, so a NULL head does not exit
the loop — it dereferences NULL + 0x178.
