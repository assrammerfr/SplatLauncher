Status: NOT a Gate 1 pass. First runnable unit still has not reached nnMain.
Gate 1 pass bar, unchanged: recompiled rtld + main (+ sdk) runs to nnMain
with a GetService log.

## What changed
- `tools/gen.py`: REIr table is now report-only. It previously mis-decoded
  the table with the wrong size tag (0x25 = DT_RELRENT, the 8-byte entry
  size, instead of 0x23 = DT_RELSZ, the table size) and treated entries as
  word indices instead of byte offsets, so it processed about one entry
  per module.
- `src/runtime/nso_loader.c`: the loader now owns REIr application at
  load time, with the correct tag (DT_RELR 0x24 / DT_RELSZ 0x23) and
  byte offsets. gen.py keeps RELA baking; nothing double-rebases.
- Runtime source also updated in this snapshot: `a64.py`, `a64_ctx.h`,
  `a64_helpers.c`, `main.c`, `build.py`, and `gen_report.json`.
